Chapter 2: Convex sets

Definition of convexity

Excercise 2.1

Let 𝐶⊂ℝ𝑛 be a convex set, with 𝑥1,…,𝑥𝑘∈𝐶, and 𝜃1,…,𝜃𝑘∈ℝ satisfy 𝜃𝑖≥0, 𝜃1+…+𝜃𝑘=1. Show that 𝜃1𝑥1+…+𝜃𝑘𝑥𝑘∈𝐶. (The definition of cenvexity is that this holds for 𝑘=2; you must show it for arbitrary 𝑘. ) Hint. Use induction on 𝑘.

Proof: 𝑘 に関する帰納法で示す. 𝑘=2 のとき定義から明らか. 𝑘=ℓ のとき成り立つとして 𝑘=ℓ+1 のとき成立することを示す. 𝜃ℓ+1=1 の場合 𝜃1𝑥1+…+𝜃ℓ+1𝑥ℓ+1=𝑥ℓ+1∈𝐶 となるため 𝜃ℓ+1<1 であるとする. このとき 𝜃1+…+𝜃ℓ=1−𝜃ℓ+1 であることから

𝑦≔𝜃11−𝜃ℓ+1𝑥1+…+𝜃ℓ1−𝜃ℓ+1𝑥ℓ∈𝐶

が成り立ち, 凸集合の定義から (1−𝜃ℓ+1)𝑦+𝜃ℓ+1𝑥ℓ+1∈𝐶 が成り立ち, 従って 𝜃1𝑥1+…+𝜃ℓ+1𝑥ℓ+1∈𝐶 が成り立つ. ∎

Excercise 2.2

Show that a set is convex if and only if its intersection with any line is convex. Show that a set is affine if and only if its intersection with any line is affine.

Proof: (convex, ⇒) 凸集合同士の共通部分は凸であるため任意の直線との共通部分は凸.
(convex, ⇐) 𝐶 を ℝ𝑛 の部分集合とし, 任意の直線との共通部分が凸であるとする. 任意の 𝑥1,𝑥2∈𝐶 に対し, 𝑥1 と 𝑥2 を結ぶ直線を 𝐿 とすれば 𝐿∩𝐶 は仮定より凸である. 𝑥1,𝑥2∈𝐿∩𝐶 より任意の 𝜃∈[0,1] に対し

𝜃𝑥1+(1−𝜃)𝑥2∈𝐿∩𝐶⊂𝐶

であり, 従って 𝐶 は凸である.
(affine, ⇒) 𝐶⊂ℝ𝑛 を affine 集合とし, 𝐿⊂ℝ𝑛 を任意の直線とする. 𝐿∩𝐶 が空集合か 1 点集合である場合, それは明らかに affine である. 𝐿∩𝐶 が 2 つ以上の要素を持つとし, それを 𝑥1,𝑥2 とおく. 𝐿 は 𝑥1,𝑥2 を通る直線であり, 𝐶 が affine であることの定義から 𝐶 内の異なる 2 点を通る直線は 𝐶 に含まれるため 𝐿∩𝐶=𝐿 である. 𝐿 は直線であるから affine である.
(affine, ⇐) 𝐶 を ℝ𝑛 の部分集合とする. 𝑥1,𝑥2 を 𝐶 内の任意の異なる 2 点とし, 𝑥1,𝑥2 を通る直線を 𝐿 とする. 仮定より 𝐶∩𝐿 は affine であり, 従って 𝐶∩𝐿 内の異なる 2 点を通る直線は必ず 𝐶∩𝐿 に含まれる. 従って 𝐿⊂𝐶 であり 𝐶 自身も affine である. ∎

Excercise 2.3 (Midpoint convexity)

A set 𝐶 is midpoint convex if whenever two points 𝑎,𝑏 are in 𝐶, the average or midpoint (𝑎+𝑏)/2 is in 𝐶. Obviously a convex set is midpoint convex. It can be proved that under mild conditions midpoint convexity implies convexity. As a simple case prove that if 𝐶 is closed and midpoint convex, then 𝐶 is convex.

Proof: 𝐶⊂ℝ𝑛 を midpoint convex set とし, 閉集合であるとする. 𝑥1,𝑥2 を 𝐶 内の任意の異なる 2 点とする. このとき任意の実数 𝜃∈[0,1] に対して 𝜃𝑥1+(1−𝜃)𝑥2∈𝐶 を示せばよい.
𝑓:[0,1]→𝑅𝑛 を 𝑓(𝑡)=𝑡𝑥1+(1−𝑡)𝑥2 と定義する. 𝜃l(0)=0, 𝜃r(0)=1 とおくと 𝑓(𝜃l(0))=𝑥1∈𝐶, 𝑓(𝜃r(0))=𝑥2∈𝐶 である. 𝐶 は midpoint convex であるから 𝑓((𝜃l(0)+𝜃r(0))/2)∈𝐶 である. 𝜃l(1), 𝜃r(1) を次のように定める.

𝜃≤𝜃l(0)+𝜃r(0)2⇒{𝜃l(1)=𝜃l(0)𝜃r(1)=𝜃l(0)+𝜃r(0)2𝜃>𝜃l(0)+𝜃r(0)2⇒{𝜃l(1)=𝜃l(0)+𝜃r(0)2𝜃r(1)=𝜃r(0)

このとき 𝑓(𝜃l(1))∈𝐶 かつ 𝑓(𝜃r(1))∈𝐶 である. 任意の 𝑘∈ℕ に対しても同様に 𝜃l(𝑘),𝜃r(𝑘) から 𝜃l(𝑘+1),𝜃r(𝑘+1) を定めると 𝑓(𝜃l(𝑘))∈𝐶 かつ 𝑓(𝜃r(𝑘))∈𝐶 であり, 次のようになる.

𝜃l(0)≤𝜃l(1)≤…≤𝜃l(𝑘)≤…≤𝜃≤…≤𝜃r(𝑘)≤…≤𝜃r(1)≤𝜃r(0)

更に点列 {𝜃l(𝑘)}𝑘=1∞, {𝜃r(𝑘)}𝑘=1∞ は共に 𝜃 に収束する. 𝑓 が連続である事から lim𝑘→∞𝑓(𝜃l(𝑘))=𝑓(𝜃) であり, 𝐶 が閉集合であることから 𝑓(𝜃)∈𝐶 である. 従って 𝐶 は凸集合である. ∎

Excercise 2.4

Show that the convex hull of a set 𝑆 is the intersection of all convex sets that contain 𝑆. (The same method can be used to show that the conic, or affine, or linear hull of a set 𝑆 is the intersection of all conic sets, or affine sets, or subspaces that contain 𝑆.)

Proof: 𝐶1=conv𝑆 とし, 𝐶2 を 𝑆 を含む全ての凸集合の共通部分とする.
(𝐶1⊂𝐶2) 𝑥1,…,𝑥𝑘 を 𝑆 内の任意の 𝑘 点, 𝜃1,…,𝜃𝑘 は 𝜃𝑖≥0, 𝜃1+…+𝜃𝑘=1 を満たす任意の実数とする. 𝑆 を含む任意の凸集合 𝐶 について 𝜃1𝑥1+…+𝜃𝑘𝑥𝑘∈𝐶 であるから 𝜃1𝑥1+…+𝜃𝑘𝑥𝑘∈𝐶2 であり, 従って 𝐶1⊂𝐶2 である.
(𝐶1⊃𝐶2) 𝐶1=conv𝑆 は 𝑆 を含む凸集合であるため, 𝐶2 の定義における “𝑆 を含む全ての凸集合” に属する. 従って 𝐶1⊃𝐶2 である. ∎

Examples

Excercise 2.5

What is the distance between two parallel hyperplanes {𝑥∈ℝ𝑛|𝑎𝑇𝑥=𝑏1} and {𝑥∈ℝ𝑛|𝑎𝑇𝑥=𝑏2}?

Proof: 1 つ目の集合を 𝑆1, 2 つ目の集合を 𝑆2 とする. これらの距離とは

dist(𝑆1,𝑆2)=inf{‖𝑢−𝑣‖2|𝑢∈𝑆1,𝑣∈𝑆2}

で定義される. 点と超平面の距離の公式 (ラグランジュの未定乗数法を用いて求める) より

dist(𝑆1,𝑆2)=inf{‖𝑢−𝑣‖2|𝑢∈𝑆1,𝑣∈𝑆2}=inf𝑢∈𝑆1inf𝑣∈𝑆2‖𝑢−𝑣‖2=inf𝑢∈𝑆1|𝑎𝑇𝑢−𝑏2|‖𝑎‖=|𝑏1−𝑏2|‖𝑎‖

となる. ∎

Excercise 2.6

When does one halfspace contain another? Give conditions under which

{𝑥|𝑎𝑇𝑥≤𝑏}⊆{𝑥|𝑎̂𝑇𝑥≤𝑏̂}

(where 𝑎≠0, 𝑎̂≠0). Also find the conditions under which the two halfspaces are equal.

Proof: 𝑆1={𝑥|𝑎𝑇𝑥≤𝑏}, 𝑆2={𝑥|𝑎̂𝑇𝑥≤𝑏̂} とおき, 𝐻1={𝑥|𝑎𝑇𝑥=0}, 𝐻2={𝑥|𝑎̂𝑇𝑥=0} とおく. 𝑆1⊆𝑆2 であるためには 𝑎̂ が 𝑎 の正の定数倍かつ 𝑏/‖𝑎‖≤𝑏̂/‖𝑎̂‖ でなければならないことを示す. まず, 𝐻1⊆𝐻2 であることを示す. 背理法のため 𝑣∈𝐻1 が 𝑣∉𝐻2 を満たすと仮定する. 必要なら負の定数倍をすることで 𝑎̂𝑇𝑣>0 としてよい. このとき任意の 𝑥0∈𝑆1 と任意の実数 𝑡 に対して 𝑥0+𝑡𝑣∈𝑆1 であるが, 十分大きい 𝑡 に対して 𝑥0+𝑡𝑣∉𝑆2 となる. 従って 𝐻1⊆𝐻2 とわかる. 更に 𝐻1 と 𝐻2 の次元は等しいため 𝐻1=𝐻2 である. 超平面に対する直交補空間は 1 次元であるため, 𝑎 と 𝑎̂ は定数倍で互いに移り合う. 次はその定数が正であることを示す. 背理法のため 𝑎̂=𝑠𝑎 (𝑠<0) と仮定する. このとき 𝑎𝑇𝑣<0 なる 𝑣 をとると 𝑎̂𝑇𝑣=𝑠𝑎𝑇𝑣>0 である. 任意の 𝑥0∈𝑆1 と十分大きい正の実数 𝑡 に対して 𝑥0+𝑡𝑣∈𝑆1 であるが 𝑥0+𝑡𝑣∉𝑆2 である. 従って 𝑎̂ は 𝑎 の正の定数倍である. 最後に, 𝛼=𝑎/‖𝑎‖(=𝑎̂/‖𝑎̂‖) とおくと,

𝑆1={𝑥|𝛼𝑇𝑥≤𝑏‖𝑎‖},𝑆2={𝑥|𝛼𝑇𝑥≤𝑏̂‖𝑎̂‖}

と書け, 𝑆1⊆𝑆2 であるためには 𝑏/‖𝑎‖≤𝑏̂/‖𝑎̂‖ であることが必要だとわかる.
逆に 𝑎̂ が 𝑎 の正の定数倍かつ 𝑏/‖𝑎‖≤𝑏̂/‖𝑎̂‖ であるならば上記の 𝑆1, 𝑆2 の表現から 𝑆1⊆𝑆2 である.
2 つの半空間が等しくなるのは 𝑎 と 𝑎̂ が互いに正の定数倍で移り合い, 𝑏/‖𝑎‖=𝑏̂/‖𝑎̂‖ のときである. ∎

Excercise 2.7 (Voronoi description of halfspace)

Let 𝑎 and 𝑏 be distinct points in ℝ𝑛. Show that the set of all points that are closer (in Euclidean norm) to 𝑎 than 𝑏, i.e., {𝑥|‖𝑥−𝑎‖2≤‖𝑥−𝑏‖2} is a half space. Describe it explicitly as an inequality of the form 𝑐𝑇𝑥≤𝑑. Draw a picture.

Proof: 条件式を同値変形していくと次のようになる.

‖𝑥−𝑎‖2≤‖𝑥−𝑏‖2‖𝑥−𝑎‖22≤‖𝑥−𝑏‖22(𝑥−𝑎)𝑇(𝑥−𝑎)≤(𝑥−𝑏)𝑇(𝑥−𝑏)‖𝑥‖22−2𝑎𝑇𝑥+‖𝑎‖22≤‖𝑥‖22−2𝑏𝑇𝑥+‖𝑏‖22(𝑏−𝑎)𝑇𝑥≤‖𝑏‖22−‖𝑎‖222

従って 𝑐=𝑏−𝑎, 𝑑=(‖𝑏‖22−‖𝑎‖22)/2 とすれば {𝑥|‖𝑥−𝑎‖2≤‖𝑥−𝑏‖2}={𝑥|𝑐𝑇𝑥≤𝑑} である.
図示すると次のようになる. ここで 𝑚=(𝑎+𝑏)/2 である. ∎

Excercise 2.8

Which of the following sets 𝑆 are polyhedra? If possible, express 𝑆 in the form 𝑆={𝑥|𝐴𝑥⪯𝑏,𝐹𝑥=𝑔}.

  1. (a)
    𝑆={𝑦1𝑎1+𝑦2𝑎2|−1≤𝑦1≤1,−1≤𝑦2≤1}, where 𝑎1,𝑎2∈ℝ𝑛
  2. (b)
    𝑆={𝑥∈ℝ𝑛|𝑥⪰0,𝟏𝑇𝑥=1,∑𝑖=1𝑛𝑥𝑖𝑎𝑖=𝑏1,∑𝑖=1𝑛𝑥𝑖𝑎𝑖2=𝑏2}, where 𝑎1,…,𝑎𝑛∈ℝ and 𝑏1,𝑏2∈ℝ.
  3. (c)
    𝑆={𝑥∈ℝ𝑛|𝑥⪰0,𝑥𝑇𝑦≤1,for all𝑦with‖𝑦‖2=1}
  4. (d)
    𝑆={𝑥∈ℝ𝑛|𝑥⪰0,𝑥𝑇𝑦≤1,for all𝑦with∑𝑖=1𝑛|𝑦𝑖|=1}

Proof: (a), (b), (d) が多面体であり, (c) だけが多面体でない.

  1. (a)
    𝑎1 と 𝑎2 が線形独立の場合のみ示す. このとき 𝐵≔(𝑎1,𝑎2)∈ℝ𝑛×2 はランク 2 のため一般化逆行列 𝐵+=(𝐵𝑇𝐵)−1𝐵𝑇∈ℝ2×𝑛 が定まり 𝐵+𝐵=𝐼2 となる. S を表す等式制約として 𝑥 が 𝑎1, 𝑎2 が張る空間に属するということを直交射影を用いて表す. すなわち 𝐵𝐵+𝑥=𝑥. これは 𝐹=𝐵𝐵+−𝐼, 𝑔=𝟎 と対応する. 不等式制約として 𝑥 が 𝑦1𝑎1+𝑦2𝑎2 がなす平行四辺形に入ることを表す. 𝐵+𝐵=𝐼2 であることから 𝐵+ の各行ベクトル 𝑐1𝑇, 𝑐2𝑇 は 𝑐𝑖𝑇𝑎𝑗=𝛿𝑖𝑗 を満たす. この 𝑐𝑖𝑇 を用いて 𝑦𝑖 の範囲を制限すれば良い. つまり 𝐴=(𝑐1,𝑐2,−𝑐1,−𝑐2)𝑇, 𝑏=𝟏4 とすればよい.
  2. (b)
    𝛼1=(𝑎1,…,𝑎𝑛)𝑇∈ℝ𝑛 とし, 𝛼2=(𝑎12,…,𝑎𝑛2)𝑇∈ℝ𝑛 とする. 𝐴=−𝐼𝑛, 𝑏=𝟎, 𝐹=(𝟏𝑛,𝛼1,𝛼2)𝑇, 𝑔=(1,𝑏1,𝑏2)𝑇 とすればよい.
  3. (c)
    この 𝑆 は単位球体 𝐵(0,1) に等しい. 実際, 𝑥∈𝐵(0,1) とすると任意の単位球面上のベクトル 𝑦 に対して 𝑥𝑇𝑦≤1 なので 𝑥∈𝑆 であるし, 𝑥∉𝐵(0,1) とすると 𝑦=𝑥/‖𝑥‖ に対して 𝑥𝑇𝑦=‖𝑥‖>1 となってしまい 𝑥∉𝑆 である. 単位球体は多面体ではない.
  4. (d)

    max‖𝑦‖1=1𝑥𝑇𝑦=‖𝑥‖∞ である (ヘルダーの不等式の特別な場合). 実際, 𝑥𝑇𝑦 を最大化するには絶対値が最も大きい 𝑥 の成分 𝑥𝑖 の符号に応じて 𝑦𝑖=1if𝑥𝑖>0else𝑦𝑖=−1 とすればよい (𝑦 の 𝑖 成分以外は全て 0). つまり 𝑆={𝑥∈ℝ𝑛|𝑥⪰𝟎,‖𝑥‖∞≤1} と書ける. 𝐴=(𝐼𝑛,−𝐼𝑛)𝑇, 𝑏=(𝟏𝑛𝑇,𝟎𝑛𝑇)𝑇 とおけば

    𝑆={𝑥∈ℝ𝑛|𝑥⪰𝟎,‖𝑥‖∞≤1}={𝑥∈ℝ𝑛|𝟎⪯𝑥⪯𝟏}={𝑥∈ℝ𝑛|𝐴𝑥⪯𝑏}

    と書ける. ∎
